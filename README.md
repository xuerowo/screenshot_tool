# 定點連續截圖工具 — 精準對齊版

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
![Platform](https://img.shields.io/badge/platform-Windows-blue)
![Python](https://img.shields.io/badge/python-3.11%2B-blue)

一個 Windows 桌面工具：對使用者指定的**一個或多個**螢幕定點區域進行**連續截圖**，並確保**選定 / 調整區域時能精準對齊目標範圍**。

技術棧：Python 3.11 + PyQt6 + mss。

## 核心特色

### 精準對齊
- **Per-Monitor V2 DPI 感知**：進入點 `main.py` 先設定 DPI 感知，讓 Qt 與 mss 都以**物理像素**作業，座標 1:1 對齊螢幕實際像素。
- **縮放螢幕一致轉換**：在縮放倍率 >100%（例如 150%）的螢幕上，Qt 使用「邏輯」像素而 mss 使用「物理」像素；遮罩模組在兩者間一致轉換，抓取結果與所見完全對齊（這是一般截圖工具錯位的常見根源）。
- **十字游標 + 像素網格放大鏡 (Loupe)**：遮罩在整個螢幕上使用**十字準線游標**；游標附近像素以 2x/4x/8x 放大，疊加**像素網格**與**十字準線**，以物理解析度繪製，可判斷到單一像素。
- **滑鼠微調選定區域**：
  - **移動**：按住選取框**內部**拖曳，可整體平移選取範圍。
  - **縮放**：按住四周的 **8 個控制點（四角 + 四邊中點）**拖曳，可單邊或對角微調大小；游標靠近控制點時會自動切換成對應的縮放游標。
- **貼齊視窗邊緣 (Snap)**：拖曳邊界接近任一視窗邊界時自動吸附（Win32 `EnumWindows`）。
- **1px 微調**：方向鍵移動 1px、Shift+方向鍵 10px、Ctrl+方向鍵移動單邊 1px。
- **數值座標輸入**：主視窗直接輸入 Left/Top/Width/Height（物理像素）。
- **選取游標下視窗**：一鍵抓取目標視窗（含擴展外框）。

### 多個定點
- 可新增任意數量的定點區域，每一輪擷取會把**所有定點各拍一張**（同一輪共用時間戳與輪次編號）。
- **調整順序**：在清單中直接拖曳，或用 ↑ / ↓ 按鈕。清單順序 = 每輪拍攝順序 = `Ctrl+Alt+N` 的編號。
- 每個定點有名稱（預設 `P1`、`P2`…，可改名），可透過檔名格式的 `{名稱}` 寫進檔名（見下方「檔名格式」）。
- 選取遮罩中，其他已設定的定點會以**橘色虛線框**標示，方便對齊或避免重疊；「重新選取」會以原區域為起點微調。
- 舊版 `config.json` 的單一區域會自動轉成定點 `P1`。

### 連續擷取
- 三種節奏：**定時間隔（秒）**、**每秒幀數 (FPS)**、**翻頁連拍**（見下方）。
- 輪數 / 秒數上限（0 = 無限；每輪 = 所有定點各一張）。
- 開始 / 暫停 / 恢復 / 停止；**手動加拍**。
- **立即單張**：不進連續模式也能把所有定點各擷取一張並儲存；或用 **Ctrl+Alt+1～9** 只拍指定的那一個定點。
- 左側定點預覽**即時更新**（約每秒 5 張，背景執行緒抓取不卡介面；視窗最小化 / 框選時自動暫停）。
- 擷取預覽（顯示清單中選中的定點最新存下的那張）+ 統計（輪數 / 張數 / 大小 / 耗時 / 每輪抓取耗時）。

### 翻頁連拍
「擷取節奏」選 **翻頁連拍**：**先拍當前頁**，接著 **按翻頁鍵 → 等待 → 同時拍所有定點**，重複到「上限 N 輪」（或按停止）。N 輪 = 拍 N 頁、翻 N−1 次，最後一輪拍完不會再翻頁。

- 翻頁鍵可選 ← → ↑ ↓、Page Up / Down、空白鍵、Enter；按鍵會送到**最前面的視窗**（例如閱讀器）。
- 「按鍵後等」：翻頁後等多久再拍，讓畫面載入完成。
- 「開始倒數」：在主視窗按開始時，倒數期間請點一下要翻頁的視窗。用**迷你模式**的 ▶ 開始時工具列不會搶焦點，可設為不倒數。
- 用 **Ctrl+Alt+S** 開始最方便：閱讀器保持在最前面、自動略過倒數；程式會等你放開 Ctrl / Alt 後才送出翻頁鍵（避免變成 Ctrl+Alt+← 這類組合鍵）。
- 安全措施：若最前面的是本程式視窗，不會送出按鍵，並停止擷取、提示原因。
- 範例（雙頁閱讀器，定點 A = 左頁、B = 右頁，檔名 `{序號}_{名稱}`）：
  手動 `Ctrl+Alt+2` 拍第一張 B → 手動按 ← → `Ctrl+Alt+S` 開始翻頁連拍 N 輪（拍 A、B → ← → 拍 A、B …）→ 手動按 ← 再 `Ctrl+Alt+1` 拍最後一張 A。

### 迷你模式
- 主視窗右上角「⤡ 迷你模式」（或 `Ctrl+M`）把主視窗收成一條浮動小工具列，只留拍攝會用到的按鈕：
  開始 / 暫停 / 停止 / 手動加拍、`◎ 全部`（立即單張）、`1` `2` `3`…（只拍該定點）、目前狀態與輪次、`⤢` 展開。
- 工具列置頂、可拖曳（按住空白處或左側 ⠿），位置會記住。
- **不會被拍進截圖**：工具列設為排除螢幕擷取（Windows 10 2004 以上），即使蓋在定點上，截圖拍到的也是它後面的畫面。
- 按 `⤢`、雙擊工具列空白處或 Alt+F4 回到主視窗；全域快捷鍵在迷你模式下照常可用。

### 介面
- 現代深色主題：卡片式分區、主要 / 危險按鈕配色、狀態膠囊（待機 / 擷取中 / 已暫停）、Windows 深色標題列。
- 顏色集中在 `theme.py` 的 `COLORS`，可自行調整。

### 其他
- 設定持久化於 `config.json`（定點清單、節奏、輸出目錄、格式等）。
- PNG / JPEG 輸出、檔案前綴、輸出目錄（GUI 選擇）、自訂檔名格式。
- 全域快速鍵 `F9`（若 `keyboard` 模組可用）進行手動加拍。

## 檔名格式

在「輸出 → 檔名」設定，可從下拉選單選預設格式，或自行輸入；「插入代號」選單可把代號插到游標處，下方會即時顯示範例檔名（格式有誤時以紅字提示，並擋下擷取）。

| 代號 | 內容 |
|------|------|
| `{前綴}` | 輸出設定中的「前綴」 |
| `{名稱}` | 定點名稱，例如 `P1` |
| `{編號}` | 定點在清單中的編號 `1`、`2`、`3`… |
| `{日期}` | `YYYYMMDD` |
| `{時間}` | `HHMMSS` |
| `{毫秒}` | `000`–`999` |
| `{輪次}` | 連續擷取的輪次 `0001`…；立即單張為 `single` |
| `{序號}` | 該資料夾中的第幾張照片 `0001`…（接續資料夾內現有的 png / jpg 數量） |

- 預設：`{前綴}_{名稱}_{日期}_{時間}_{毫秒}_{輪次}` → `capture_P1_20260928_170853_467_0001.png`
- 用 `/` 建立子資料夾，例如 `{名稱}/{前綴}_{日期}_{時間}_{毫秒}_{輪次}` 會替每個定點建一個資料夾。
- `{序號}` 依「存放的資料夾」計算，**每次存檔都重新數資料夾內的照片**（刪掉幾張後再拍，號碼會接著目前的張數）：搭配 `{名稱}/{序號}` 時每個定點各自從 0001 編號；全部放同一資料夾時所有定點共用一組序號。號碼已被佔用（例如中間刪過檔）會自動往後找。`{序號}` 只能用在檔名，不能放在資料夾名稱。
- 代號也可用英文別名：`{prefix}` `{name}` `{no}` `{date}` `{time}` `{ms}` `{round}` `{seq}`。
- 產生的檔名若已存在，會自動加上 `_1`、`_2`… 不會覆蓋舊檔；Windows 不允許的字元與 `..` 會被移除。

```bash
pip install -r requirements.txt
```

## 執行

- **Windows**：雙擊 `start.bat`，或
- 手動：`python main.py`

## 使用流程
1. 在主視窗按「**＋ 新增定點…**」，畫面出現全螢幕遮罩。
2. 用滑鼠拖曳出要擷取的範圍（可使用放大鏡與十字準線對齊像素邊界，靠近視窗邊緣會自動吸附）。
3. **微調（滑鼠）**：拖曳選取框**內部**可整體平移；拖曳四周 **8 個控制點**可縮放邊界。
4. **微調（鍵盤）**：方向鍵（1px）、Shift+方向鍵（10px）、Ctrl+方向鍵（單邊）；或點「選取游標下視窗」一鍵選定。
5. 按 **Enter** 確認（**Esc** 取消），定點會加入清單。
6. 需要更多定點就重複 1–5；已設定的定點會在遮罩中以橘色虛線框顯示。
7. 在清單點選定點後，可用數值欄位 / 微調按鍵精確修改，或「重新選取」「改名」「刪除」；拖曳清單項目或按 ↑ / ↓ 可調整順序。
8. 設定節奏（間隔 / FPS）、輸出目錄、格式後按「**開始**」；或按「**立即單張**」先把每個定點測試一張。

## 快速鍵（遮罩內）
| 鍵 | 動作 |
|----|------|
| Enter | 確認 |
| Esc | 取消 |
| 方向鍵 | **微調滑鼠位置** 1px |
| Shift+方向鍵 | 微調滑鼠位置 10px |
| Ctrl+方向鍵 | 調整對應單邊 1px |
| ＋ / － | 放大鏡倍率 |
| H | 隱藏 / 顯示底部控制面板 |

方向鍵直接移動「滑鼠游標」（物理像素），讓您在框選 / 移動 / 縮放時都能用鍵盤精準對齊；按住拖曳中按方向鍵也會同步微調框。

遮罩內游標：預設十字準線；靠近控制點時轉為縮放游標、按住選取框內部時轉為移動游標。

控制面板不會擋住要選的地方：拖曳（框選 / 移動 / 縮放）時自動隱藏；選取框在畫面下方時面板自動移到上方；放大鏡被面板擋住時會改顯示在游標上方。

## 主視窗快捷鍵

按主視窗右上角的「?」按鈕（或 F1）可隨時叫出快捷鍵表。
| 鍵 | 動作 | 範圍 |
|----|------|------|
| **F6** | 新增定點（開啟全螢幕遮罩） | 全域（需 `keyboard` 模組） |
| **F7** | 重新選取目前定點（沒有定點時為新增） | 全域（需 `keyboard` 模組） |
| **F8** | 立即單張（所有定點各擷取並儲存一張） | 全域（需 `keyboard` 模組） |
| **Ctrl+Alt+1～9** | 只拍第 1～9 個定點一張（清單上的 `[N]` 編號） | 全域（需 `keyboard` 模組） |
| **Ctrl+Alt+S** | 開始擷取 / 停止（擷取中再按一次即停止） | 全域（需 `keyboard` 模組） |
| **Ctrl+Alt+P** | 暫停 / 恢復 | 全域（需 `keyboard` 模組） |
| **F9** | 手動加拍一輪（連續擷取運行中） | 全域（需 `keyboard` 模組） |
| Ctrl+R | 重新選取目前定點 | 視窗有焦點時 |
| Ctrl+M | 迷你模式 | 視窗有焦點時 |
| F1 | 快捷鍵一覽 | 視窗有焦點時 |
| Ctrl+S | 立即單張 | 視窗有焦點時 |

> 全域 F6 / F7 / F8 / F9 / Ctrl+Alt+數字 / Ctrl+Alt+S / Ctrl+Alt+P 由 `keyboard` 模組提供，可能需以管理員權限執行；若未安裝，F6 / F9 / Ctrl+Alt+數字 / Ctrl+Alt+S / Ctrl+Alt+P 改為視窗有焦點時有效，其餘以按鈕／Ctrl+R、Ctrl+S 代替。

## 專案結構
```
screenshot_tool/
  main.py          進入點（先設 DPI 感知）
  app.py           主視窗控制面板
  mini_bar.py      迷你模式浮動工具列（不被截圖）
  region.py        全螢幕選取遮罩（放大鏡/網格/貼齊/微調）
  cap_engine.py    連續擷取引擎（背景執行緒 + mss）
  theme.py         深色主題（樣式表 / 調色盤，改色只需改 COLORS）
  assets/          主題用的 SVG 圖示（箭頭、勾選）
  winapi.py        DPI 感知 / 視窗列舉 / 虛擬桌面幾何
  config.py        設定持久化
  smoke_test.py    冒煙測試（python smoke_test.py）
  requirements.txt 相依套件
  start.bat        Windows 一鍵啟動
  LICENSE          MIT 授權條款
  .gitignore
```

python smoke_test.py

## 注意事項
- 需要 Python 3 + 上述套件；縮放螢幕已由 DPI 感知處理。
- 全域 F9 快速鍵需 `keyboard` 模組，且可能需以管理員權限執行。
- `config.json` 為**本機執行期設定**（內含你的輸出目錄與定點清單），已列入 `.gitignore` 不進版控；檔案不存在時程式會自動採用預設值，並於儲存設定時建立。
- 截圖輸出目錄 `screenshots/` 同樣不進版控。
